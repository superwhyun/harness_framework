현재 세션에서 대상 프로젝트 규칙을 적용해 사용자 요청을 수행하라. 이미 로딩된 지침은 다시 읽지 않는다.

$ARGUMENTS

작은 수정은 바로 구현·검증한다. 큰 작업은 기존 계획 또는 tasks/{task}.md 하나에 목표·설계와
단위별 범위·완료 조건·선행 단위·검증 방법·상태를 기록한다. 현재 세션에서 준비된 단위를
하나씩 구현·검증하고 통과 결과와 해당 변경을 함께 커밋한 뒤 다음 단위로 진행한다.
분리하면 동작하지 않는 작은 step은 묶어 커밋한다. phase 종료 시 통합 검증 후 추가 변경이 있을 때만 커밋한다.
무관한 기존 변경은 포함하지 않는다. 대상 정책·사용자 명시 지시를 우선하고 push·태그는 별도 요청을 따른다.
작업 전체를 한 구현 단위로 몰지 않는다. 별도 Claude·Codex CLI나 새 세션을 호출하지 않는다.
선택적 scripts/scaffold_task.py는 문서만 생성한다. 상세는 필요할 때 docs/HARNESS.md를 읽는다.
재개 시 관련 task 또는 기존 phase의 pending 작업을 확인한다. 기존 이력을 보존한다.
종료·인계 전에 검증 결과와 다음 행동을 남긴다. 관련 변경이 없는 통과 검사는 반복하지 않는다.
대상 경로가 명시되면 우선한다. 프레임워크 자체 요청은 현재 저장소, 다른 프로젝트 선택에만 .harness/current_project를 참고한다.
